# Install Bashi in Claude Desktop

1. Download `Bashi.mcpb` from this folder.
2. Double-click it (or open Claude Desktop, then Settings, Extensions, and drag the file in).
3. Click Install. There is nothing to type in: no keys, no database, no config file.
4. Ask Claude: "Using Bashi, can customer C001 take 45000 naira on credit? Shop is shop_a."
5. You should get NO, because of broken promise PR001, plus a receipt link. The data is an invented demo shop.
